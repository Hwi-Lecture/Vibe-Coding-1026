# 동적 난방 연료비 대시보드

기존 화면을 유지하고 FastAPI에서 날짜별 데이터를 제공합니다. 기존 파일과 데이터를 수정하지 않습니다.

## 실행 (PowerShell)

이 README가 있는 단계 폴더를 Antigravity에서 열고:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

브라우저에서 http://127.0.0.1:8000 으로 접속하세요. HTML 파일을 직접 여는 방식이 아닙니다.

## API 키

`OPINET_API_KEY` 환경변수 또는 이 폴더의 `.env`에 `opinet_api_key=발급받은키`를 설정합니다.
실습 루트와 이 폴더의 `.env`를 합쳐 읽고, 이 폴더 값을 우선합니다. 키는 브라우저에 전달하지 않습니다.
저장된 당일 자료만 사용하는 경우 API 키 없이도 표시됩니다.

## 자동 갱신 및 캐시

- 페이지 접속 시 `GET /api/dashboard`를 호출합니다. 응답은 `data`와 `meta`로 구성됩니다.
- 한국 시간의 오늘을 수집 기준일로 사용합니다. 오늘 당일 가격이 아니라 어제까지의 최근 7일과 직전 7일을 비교합니다.
- 자동으로 찾은 `data/opinet/날짜/`의 수집 완료 CSV를 검증해서 최초 캐시로 가져옵니다. 기존 JSON 경로를 기록한 manifest와 변환된 CSV 구조도 지원합니다.
- 캐시는 `storage/snapshots/YYYY-MM-DD.json`에 영구 저장됩니다. 같은 날 재접속과 서버 재시작에는 외부 API 호출이 없습니다.
- 날짜가 바뀌면 이전 자료를 먼저 반환하면서 별도 스레드에서 수집합니다. 캐시가 전혀 없으면 HTTP 202와 수집 상태를 반환합니다.
- 갱신 중인 화면은 2초마다 결과를 확인합니다. 평상시에는 1분마다 서버 캐시를 확인하므로 페이지를 계속 열어 둬도 날짜 변경에 대응합니다. 이 확인 자체가 매번 오피넷 호출을 일으키지는 않습니다.
- 프로세스 내부 잠금과 프로세스 간 파일 잠금으로 중복 수집을 막습니다. 여러 프로세스는 동일한 저장 경로를 사용해야 합니다.
- 수집 결과의 날짜, 중복, 전국·상표·지역 자료 및 지역코드별 포함 여부를 검증한 뒤에만 캐시를 원자적으로 교체합니다. 유종별 7일 관측이 부족한 항목은 기존 화면처럼 ‘자료 부족’으로 표시합니다.
- 수집 실패나 자료 미게시 시 기존 캐시를 유지하고 30분 뒤 다음 조회부터 재시도합니다. 대기시간은 재시작해도 유지됩니다.
- 수집 도중 서버가 중단되면 OS가 파일 잠금을 해제하고, 다음 요청에서 다시 시도합니다. 일부 외부 호출이 이미 실행되었을 수 있으므로 실패·중단 시 하루 37회가 절대 상한은 아닙니다.
- 현재 수집 방식은 정상적인 새 날짜 전체 수집에 37회(지역코드 1 + 2기간 × (전국 1 + 상표 1 + 지역 16))를 사용합니다. 일별 증분 수집은 포함하지 않았습니다.
- 방문자가 없으면 수집하지 않습니다. 별도 정기 수집이 필요하면 추후 스케줄러를 붙일 수 있습니다.

## 파일 구성

- `app.py`: HTML·정적 파일·API 제공
- `service.py`: CSV 변환, 날짜 캐시, 잠금, 백그라운드 갱신 및 재시도
- `collector.py`: 기존 수집기를 함수로 분리한 독립 모듈
- `static/index.html`, `static/dashboard.js`: 화면과 자동 데이터 로딩
- `storage/`: 실행 중 생성되는 캐시와 수집 작업 공간

화면용 데이터는 CSV에서 직접 만들며, Excel 생성이나 이메일 발송은 실행하지 않습니다.

## 저장 자료와 경로

제공된 폴더 안에서는 실습 루트의 data/opinet 또는 앞 단계 체크포인트의 CSV를 자동으로 찾습니다. 이 단계만 다른 곳으로 복사할 때는 앞 단계의 data 폴더도 현재 폴더 안으로 복사하세요. 키가 없으면 저장된 이전 자료를 표시하고 갱신 실패 상태를 안내합니다.

설정은 실습 루트의 .env와 현재 단계의 .env를 합치고 현재 단계 값을 우선합니다. 환경변수가 가장 우선합니다. 설정 파일에는 필요한 항목만 넣으면 됩니다.

## 서버 배포

Python 서버와 영구 디스크를 사용하세요. `DASHBOARD_STORAGE` 환경변수로 저장 경로를 변경할 수 있습니다. 여러 서버 인스턴스가 각자 다른 로컬 디스크를 사용하는 구성에서는 공용 DB·잠금 저장소로 전환해야 합니다. 기본 실행 주소는 이 PC에서만 접근 가능합니다.

## 상단 유가 브리핑

`briefing.py`에서 전국 일별 자료를 집계해 최근 7일과 직전 7일을 비교합니다. 달력상 이번 주/지난주 통계는 아닙니다. 지역·유종 필터와 독립적인 전국 종합 브리핑입니다.

- 현재는 API 키 없이 실행할 수 있습니다. `briefing_preview.json`에는 2026-10-23 자료로 미리 작성한 브리핑이 있으며 화면에 ‘미리 작성한 브리핑’으로 표시됩니다. 실제 OpenAI 호출 결과가 아닙니다.
- 자료가 달라지면 예전 미리보기를 재사용하지 않고, 현재 집계 수치로 만든 간단한 요약을 표시합니다.
- 키를 사용할 준비가 되면 기존 상위 `.env` 또는 이 폴더의 `.env`에 아래 설정을 추가하세요. `.env.example`도 참고할 수 있습니다. 상위/현재 폴더 설정을 합치고 현재 폴더 값을 우선합니다. 환경변수 `OPENAI_API_KEY`, `OPENAI_MODEL`이 최우선입니다.

```dotenv
openai_api_key=발급받은키
openai_model=gpt-6-luna
```

- `GET /api/briefing` 요청을 받으면 서버가 키를 읽고 백그라운드에서 OpenAI Responses API를 호출합니다. 실행 중 키를 추가해도 다음 조회에 반영됩니다.
- 키를 브라우저에 전달하지 않으며 OpenAI에는 전국 기간별 평균·증감 집계만 전송합니다. `store: false`를 사용합니다.
- `storage/briefings/`에 데이터·모델·프롬프트 버전별로 생성 결과를 저장합니다. 같은 집계에는 페이지 재접속·서버 재시작 후에도 다시 호출하지 않습니다. 자료나 모델이 바뀌면 새 결과를 만듭니다.
- 생성 중에는 준비된 문구를 보여 주고 2초마다 결과를 확인합니다. 실패하면 30분간 재시도를 미루며 화면은 유지합니다. 동일 저장소를 쓰는 프로세스끼리는 파일 잠금으로 중복 생성을 막습니다.

공식 참고: [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [텍스트 생성과 Responses API](https://developers.openai.com/api/docs/guides/text).

## 엑셀 첨부 메일

우측 상단 ‘메일 보내기’를 열면 받는 이메일 주소, 제목, 내용을 입력할 수 있습니다.

- **메일 초안 작성**: 현재 전국 집계와 비교 기간을 `gpt-6-luna`에 전달해 본문을 작성합니다. 수신 주소와 사용자가 입력한 내용은 LLM에 보내지 않습니다. 기존 본문을 새 초안으로 교체하므로 검토·수정한 후 발송하세요. 키가 없으면 현재 수치로 만든 기본 초안을 표시하고 그 사실을 안내합니다. AI 호출 실패 시 입력된 내용을 유지합니다.
- **메일 전송**: 클릭 시 화면 기준일의 전체 전국·상표·지역 자료로 엑셀을 생성하고 Gmail SMTP로 발송합니다. 한 번에 수신자 한 명을 지정합니다. 필터로 선택한 지역에 한정된 자료가 아닙니다.
- 첨부 파일명을 누르면 발송 전에 엑셀을 내려받아 확인할 수 있습니다. 기존 엑셀의 기간별 비교·전국 일별·상표별 일별·지역별 일별 네 시트와 수식을 재사용합니다. Excel에서 열 때 비교 수식을 다시 계산합니다.
- 자료가 갱신되면 발송 요청의 데이터 식별자를 확인해 다른 기준일의 엑셀이 잘못 첨부되는 것을 방지합니다.
- 같은 발송 요청은 잠금과 `storage/mail/`의 처리 기록으로 중복 전송을 막습니다. 네트워크 오류로 접수 여부가 불확실할 때는 자동 재전송하지 않으므로 보낸메일함에서 확인하세요.
- 엑셀은 `storage/exports/`에 데이터별로 저장합니다. `mailer.py`는 메일 처리, `excel_report.py`는 기존 Excel 형식의 재사용을 담당합니다.

기존 상위 `.env`나 현재 폴더 `.env`에 다음 값을 설정하세요. 환경변수 `EMAIL_ADDRESS`, `GMAIL_APP_PASSWORD`도 지원합니다.

```dotenv
email_address=발신용_Gmail_주소
gmail_app_password=Gmail_앱_비밀번호
openai_api_key=OpenAI_API_키
openai_model=gpt-6-luna
```

의존성이 추가되었으므로 `python -m pip install -r requirements.txt`를 다시 실행하세요. 이 기능은 현재 로컬 실행 환경을 기준으로 합니다. 공개 서버로 운영하려면 발신 기능의 사용자 인증과 접근 제어를 추가해야 합니다.


`briefing_preview.json`은 API 키가 없을 때 표시하는 브리핑이므로 유지합니다. `storage/`에는 데이터 캐시와 메일 처리 기록이 저장됩니다. `__pycache__/`는 Python이 실행 중 자동 생성할 수 있습니다.
