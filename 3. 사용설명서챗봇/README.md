# 사용설명서 챗봇 체크포인트

| 단계 | 동작 |
| --- | --- |
| `1. 단순 QA 챗봇` | 문서를 전달하지 않는 일반 대화. 시스템 프롬프트 비교 |
| `2. 관련 페이지 검색 챗봇` | 검색한 요약을 화면에 표시. 원문을 AI에 전달하지 않음 |
| `3. 사용설명서 기반 챗봇` | 검색한 원문을 AI에 전달하고 답변 아래에서 확인 |

## 실행

원하는 단계 폴더를 Antigravity에서 열고 실행합니다. 다른 곳으로 복사할 때는 app.py, 검색 모듈, Markdown 자료 등 단계 폴더의 내용 전체를 복사합니다.

```powershell
python -m streamlit run app.py
```

브라우저에 표시되는 주소(기본 http://localhost:8501)로 접속합니다. 종료는 터미널에서 Ctrl+C입니다.

이 참고 코드는 OpenAI를 사용합니다. 해당 단계의 `.env.example`을 `.env`로 복사해 `openai_api_key`를 입력합니다. 모델 기본값은 기존 예제와 같은 `gpt-4o-mini`이며 `openai_model` 또는 `OPENAI_MODEL`로 바꿀 수 있습니다.

제공된 구조에서는 실습 루트인 `3. 사용설명서챗봇/.env`를 공통으로 사용할 수도 있습니다. 같은 항목은 단계 폴더의 `.env`가 우선하며 환경변수가 가장 우선합니다. 키 이름이나 API 서비스는 자동 변환하지 않습니다.

## 확인할 질문

제공된 테스트 8문항과 함께 다음 입력도 확인합니다.

- 짧은 검색: 세탁 방법, 보증 기간, 취침, 온도
- 후속 질문: 취침·수면 질문 후 “그럼 몇 시간인가요?”
- 문서 밖 정보: 배터리 규격·직접 교체 방법
- 범위 밖 질문: 김치볶음밥 조리법

3단계는 근거가 없으면 AI를 호출하지 않고 안내 범위를 설명합니다. 원문이 있어도 없는 세부사항은 추측하지 않도록 지시합니다. ‘검색해 전달한 페이지’는 AI에 전달한 후보이며 답변 전체의 정확성을 보증하지 않습니다. 펼치기에서 원문과 답변을 대조합니다.

검색은 키워드와 주제 규칙을 쓰는 간단한 방식입니다. 검색 누락과 AI 답변 오류는 별도로 확인합니다.
